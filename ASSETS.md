The geography is a poetic montage, not a single real location or historical reconstruction. The aerial scene is a continuous animated photograph, without place flags or editorial cards.

## Cloud layer — October 4, 2026

dist/assets/flight-clouds.svg is a lightweight procedural texture built with SVG turbulence, blur and soft masks. Both animated layers reuse this file. The old generated cloud image and unused chapter thumbnails have been removed; no new photos were generated. Historical assets remain recoverable in Git history.
